# Aula prática com Git e Github

## Configurando o Git

- git config --global user.name "seuUserName"
- git config --global user.email "seu@email.com"

## Validando as configurações

- git config --list

## Inicializando repositório

- git init

## Verificar arquivos

- git status

## Commit

- git add . ou <nomeDoArquivo>
